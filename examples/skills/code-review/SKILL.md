# 代码审查技能

按以下维度审查代码（每项给出：问题定位 -> 严重度 -> 建议），最后输出审查报告：

1. **错误处理**：异常是否被吞掉？失败是否显式化（fail-fast vs 静默降级）？
2. **可观测性**：关键路径是否有日志/指标？错误码契约是否清晰？
3. **边界与防御**：空输入、超长输入、并发/重入是否有处理？
4. **测试纪律**：行为是否有对应单测？边界情况是否覆盖？
5. **依赖方向**：模块依赖是否单向？是否引入上帝模块？

输出格式：
```
## 审查报告：<文件>
- [高危] <问题>：<定位> -> <建议>
- [中] <问题>：<定位> -> <建议>
- [低] <问题>：<定位> -> <建议>
## 结论：<通过/需修改>
```

审查完毕用 echo 工具输出一句总结，方便回灌对话。
