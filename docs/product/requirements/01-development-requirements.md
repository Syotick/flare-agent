# Flare Agent · 开发需求说明书

> 版本：v1.0 ｜ 日期：2026-08-27 ｜ 状态：**已确认（2026-08-27），进入 M1 设计评审**
> 上游文档：docs/product/research/01-market-and-tech-research.md

## 1. 背景与目标

- **产品**：企业级 AI Agent 平台，对标 OpenAI Codex / Claude Code / DeepSeek Harness。
- **上线要求**：可部署到真实环境、可运维、可监控、可审计、可回滚，**不是 demo**。
- **并发目标**：可**弹性扩展至百万级并发接入**（设计目标），并支撑高可用（99.95%+）。
- **平台**：部署于**阿里云**，对象存储使用**阿里云 OSS**。
- **能力**：Agent 编排 + 工具/MCP + Skills + **RAG** + 会话/记忆 + 沙箱执行 + 多模型路由 + 观测/治理/安全。
- **受众**：已掌握 demo 级 AI 开发（模型、上下文、记忆、工具、MCP、Skills）的进阶团队。

## 2. 用户与使用场景（Story）

- **S1 开发者在 Web 上发起任务**："重构 X 模块并加测试"，Agent 规划→写代码→沙箱跑测试→出 PR 供审批。
- **S2 企业用户用自然语言查内部知识库**：RAG 检索+溯源引用，命中企业内部文档（OSS 托管源）。
- **S3 平台管理员**：建租户、配模型/配额、看成本与用量、查审计日志、调限流。
- **S4 CLI/API 开发者**：通过 OpenAI 兼容 API / CLI 批量提交任务、拉取进度与结果。

## 3. 功能需求（FR）

### FR-1 Agent 编排引擎
- F1.1 支持任务规划/目标拆解、多步 agent loop（推理→工具→回填）。
- F1.2 长任务**可恢复**（checkpoint 持久化，进程/节点重启可续跑）。
- F1.3 支持**人机协作**：中途 interrupt 审批（执行、写文件、外发等敏感动作）。
- F1.4 支持**多 Agent / Subagent** 并行与结果汇总（M 级）。
- F1.5 步数/成本/时间预算上限，超限熔断并通知。
- F1.6 流式输出（SSE/WS）：token 级与事件级。

### FR-2 工具系统与 MCP
- F2.1 内置工具集：文件读写、代码执行(沙箱)、搜索、Git/PR、HTTP、SQL 等。
- F2.2 **MCP 客户端适配**：连接 MCP Server（本地/远程/SSE/Streamable HTTP）。
- F2.3 **统一 MCP 网关**：认证、授权、限流、审计、白名单；禁止 Agent 直连外部 server。
- F2.4 工具权限分级（只读/写/破坏性）+ 租户 RBAC 对齐 + 敏感工具强制审批。
- F2.5 工具调用全链路埋点与失败重试/幂等。

### FR-3 Skills 与插件
- F3.1 **Skills 包**：声明式（技能清单+提示词+资源+工具依赖），可安装/卸载/版本化。
- F3.2 技能市场（租户内共享/跨租户模板），技能包存 OSS，带校验（哈希/签名）。
- F3.3 插件机制：第三方以 MCP 或 SDK 方式扩展工具与数据源。

### FR-4 会话、项目与记忆
- F4.1 会话管理：多会话、多项目；项目级上下文（类似 CLAUDE.md 项目记忆）。
- F4.2 **分层记忆**：会话短期（Redis）→ 项目长期（PG+摘要）→ 用户/组织级（可选向量记忆）。
- F4.3 上下文工程：截断、摘要压缩、关键事实抽取、结构化记忆读写。

### FR-5 RAG 知识库
- F5.1 文档入库管线：多格式解析（PDF/Word/MD/HTML/代码/表格）→ 清洗 → 智能分块 → 嵌入 → 入向量库；**异步 + 可重试**。
- F5.2 **混合检索**（向量 + BM25/全文） + **Rerank 重排** + 溯源引用（citation）。
- F5.3 文档**版本化与增量更新**（源文件存 OSS，版本号驱动重索引）。
- F5.4 知识库权限：按租户/团队/文档粒度控制检索范围。
- F5.5 RAG 评测：离线 RAGAS + 在线命中/反馈埋点。

### FR-6 模型与推理
- F6.1 **多模型路由**：OpenAI 兼容网关，支持阿里云百炼/OpenAI/Claude/DeepSeek 自接；模型灰度与降级。
- F6.2 语义缓存、失败重试与指数退避。
- F6.3 每租户/每用户/每模型**配额与成本预算**。
- F6.4 支持流式与非流式；预留多模态（图/音频/文件）输入。

### FR-7 沙箱执行
- F7.1 不可信代码/命令在**强隔离沙箱**执行（容器级，目标 Firecracker/Kata），禁止横向访问。
- F7.2 网络出口白名单、资源（CPU/内存/磁盘/时长）限制。
- F7.3 执行结果（stdout/stderr/产物）可查看、可下载，产物落 OSS。

### FR-8 平台与治理
- F8.1 **多租户**：租户隔离（数据+资源+配额），用户体系 + SSO(OIDC)。
- F8.2 管理控制台：租户/用户/模型/配额/成本/审计/告警配置。
- F8.3 审计日志：所有敏感操作（工具调用、审批、数据导出、权限变更）不可篡改留痕。
- F8.4 公告/健康检查/版本升级/灰度发布。

### FR-9 接入方式
- F9.1 Web 控制台（任务创建、实时流、审批、历史）。**本地 Web 优先**。
- F9.2 **CLI**（对标 Claude Code 体验：项目记忆、权限提示、diff 预览）——预留。
- F9.3 **REST/OpenAI 兼容 API**（任务提交、进度、结果、webhook）——预留。

### FR-10 面试考点全覆盖（"实践 + 真理"）
- F10.1 以高级 Agent 工程师面试题库（docs/learning/01-agent-interview-questions.md）为**验收清单**，每个考点在项目中要有对应落地模块或实验。
- F10.2 重点覆盖：多路召回/混合检索/GraphRAG、记忆分层与上下文工程、工具调用与 MCP、安全（注入防护/沙箱/租户隔离）、评测、高并发系统设计、推理优化、成本控制。
- F10.3 理论文档与实现代码一一对应：**"面试答题 = 讲我们怎么落地"**。

## 4. 非功能需求（NFR）

| 编号 | 项 | 目标 |
| --- | --- | --- |
| N1 | 可用性 | ≥ 99.95%（月度），多可用区 |
| N2 | 并发 | 弹性扩展至百万级并发接入；单任务 P95 首 token < 2s（推理链路） |
| N3 | 可扩展性 | Runtime 无状态水平扩展；存储/队列/向量库按需扩容 |
| N4 | 性能 | 检索 P95 < 300ms；工具调用 P95 < 1s；长任务可异步 |
| N5 | 安全 | 多租户强隔离；RBAC+ABAC；mTLS；沙箱隔离；密钥 KMS 托管 |
| N6 | 合规 | 数据驻留、审计留存、删除权、供应商 DPA |
| N7 | 可观测 | OpenTelemetry 全链路：追踪/指标/日志/成本/评测 |
| N8 | 可运维 | 一键部署(Helm/Terraform)、滚动发布、回滚、健康检查、告警 |
| N9 | 成本 | 每租户成本可核算、可限流；缓存与模型降级降本 |
| N10 | 容错 | 重试+熔断+降级；灾备演练；任务幂等不丢不重 |

## 5. 技术栈约束（已确认 2026-08-27 ✅）

- 编排：**LangGraph（Python）**；API：**FastAPI**；Web：本地优先（Vite/React 控制台，预留 CLI/API）
- 向量库：**Milvus（主选）**；本地开发可用 Qdrant/内存向量库兜底
- 模型网关：自研 OpenAI 兼容网关（可先用 LiteLLM 起步）；默认接入 DeepSeek/通义兼容接口，多供应商可配
- 推理：可自托管 **vLLM / SGLang**（GPU 场景）
- 沙箱：**Kata Containers / Firecracker microVM**（微虚拟化强隔离），开发期 Docker 降级，沙箱 Provider 可插拔
- 对象存储：**阿里云 OSS**（生产），开发期 **MinIO** 模拟，存储层 Provider 抽象可切换
- 云：阿里云（ACK / RDS / Redis / RocketMQ / OSS / MSE）；凭证后续提供，开发阶段本地化
- 观测：OpenTelemetry + Prometheus/Grafana + Loki 或阿里云 SLS
- CI/CD：GitHub Actions + 阿里云容器镜像（ACR）+ Helm

> 云资源与凭证：开发阶段不依赖，全部组件本地 Docker 化（MinIO/Redis/PG/Milvus），保证"先开发后续提供凭证"可行。

## 7. 验收标准（DoD）

- [ ] 端到端任务可跑通（Web/CLI/API 三端）
- [ ] 长任务中断可恢复（进程 kill 后续跑不丢结果）
- [ ] RAG 命中带溯源引用；离线评测指标达标并有回归基线
- [ ] 多租户隔离通过越权测试（含红队）
- [ ] 压测报告：目标并发下 P95 延迟与错误率达标；HPA 扩容生效
- [ ] 观测完备：任意任务可一键拉出全链路 trace + 成本
- [ ] 部署自动化：一条命令/一个 Pipeline 部署到阿里云并回滚
