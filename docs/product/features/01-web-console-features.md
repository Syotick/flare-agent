# Flare Agent · Web Console 用户功能清单

> 版本：v1.0 ｜ 日期：2026-08-27 ｜ 状态：draft ｜ 负责人：产品/前端
> 读者对象：**使用 Web Console 的最终用户**
> 本文档从使用者的视角说明：现在能做什么、怎么用、边界在哪、后面会有什么。

---

## 一、这是什么

**Flare Agent Console** 是 Flare Agent 平台的 Web 前端控制台。当前（M2 阶段）是一个单页应用：

- 输入一句话描述任务 → 提交给 Agent 引擎
- Agent 在后台执行（"思考 → 调工具 → 观察 → 给结论"的循环）
- 页面**实时**展示每一步执行轨迹
- 完成后展示最终结果

> 当前后端使用 mock 模型供应商 + echo 示例工具（见「六、当前边界」），
> 界面与流程已按真实产品形态搭建，接真实模型/工具后可平滑升级。

## 二、如何打开

| 方式 | 命令 | 访问地址 |
| --- | --- | --- |
| 开发模式（前后端分离） | 终端1：make dev；终端2：make web-dev | http://localhost:5173 |
| 单进程模式（后端托管页面） | make web-build && make dev | http://localhost:8000 |

打开后你会看到一个深色控制台：顶部是品牌栏（含当前任务状态），中间是任务输入区，左侧是执行轨迹时间线，右侧是「最近任务」历史列表。

## 三、功能清单

| # | 功能 | 怎么用 | 说明 / 限制 |
| --- | --- | --- | --- |
| 1 | **任务输入与运行** | 在文本框描述任务，点「▶ 运行」 | 输入上限 10000 字符（与后端一致）；运行中禁止再次提交 |
| 2 | **立即响应（不阻塞）** | 点运行后马上拿到 task_id | 提交接口立即返回，任务在后台执行，页面不白屏 |
| 3 | **实时执行轨迹** | 运行后左侧自动滚动展示 | SSE 实时推送：actor 决策卡片、tool_executor 执行卡片、result 终态卡片 |
| 4 | **取消任务** | 运行中点「■ 取消」 | 断开流式连接、停止接收；后台任务不受前端取消影响（见边界） |
| 5 | **最大步骤设置** | 输入框「最大步骤」（1-50） | 限制 Agent 最多调工具次数，防死循环；默认 5 |
| 6 | **会话续跑（thread_id）** | 填写相同的 thread_id | 同一会话可跨请求续跑（后端 SQLite checkpoint 落盘）；留空自动生成 |
| 7 | **最近任务历史** | 右侧面板点击任意任务 | 回看该任务完整轨迹与结果；按状态着色（completed/budget_exceeded/failed/running） |
| 8 | **刷新恢复** | 直接刷新浏览器 | 当前任务地址写入 URL（#task=xxx）与本地存储，刷新后自动重连并回放轨迹 |
| 9 | **超长内容折叠** | 内容超 2000 字符时点「展开全文」 | 轨迹/结果卡有内层滚动条，不撑爆页面 |
| 10 | **错误与状态提示** | 顶部状态标签 + 错误卡片 | 连接中断/超时/参数错误都有明确提示，不会"悄悄没反应" |

## 四、执行轨迹怎么看

一次典型运行会依次出现这些卡片：

| 卡片 | 含义 | 举例 |
| --- | --- | --- |
| actor · 决定调用工具 | Agent 思考后决定调用某个工具 | 决定调用工具 echo，参数 { text: "你好" } |
| tool_executor · 执行结果 | 工具实际执行后的返回 | echo: 你好 |
| actor · 给出结论 | 观察工具结果后给出最终回答 | 完成: [echo] echo: 你好 |
| result · 任务结束 | 终态与汇总 | 状态 completed · 步骤 1 · 消息 4 |

**工具失败的卡片会带错误码**（当前对真实模型同样生效）：
- UNKNOWN_TOOL — 模型选了不存在的工具
- INVALID_ARGS — 工具参数不合法
- TOOL_EXECUTION_ERROR — 工具内部出错

失败会作为"观察"回灌给 Agent 重试，**不会让整个任务崩溃**。

## 五、任务状态说明

| 状态 | 含义 |
| --- | --- |
| pending | 已提交，等待开始执行 |
| running | 执行中（可取消） |
| completed | 正常完成，有最终输出 |
| budget_exceeded | 达到最大步骤仍没结束，被熔断保护 |
| failed | 执行过程中出错 |

## 六、当前边界（务必知悉）

1. **模型是 mock**：不会调用任何真实大模型。Agent 的"思考"是确定性的模拟逻辑（调 echo → 给结论），用于验证流程与界面。
2. **只有 echo 工具**：真实工具集（RAG 检索、代码执行、文件操作等）尚未接入。
3. **单用户 / 进程内存储**：任务列表存在后端进程内存，**重启后端后历史列表清空**（但 SQLite 里保留了图状态，同 thread_id 可续跑）。
4. **无登录认证 / 多租户**：当前不做权限隔离，属 M5+ 范围。
5. **取消的边界**：前端取消只断开观看；已在后台执行的任务会继续跑到结束。

## 七、规划中的能力（路线图）

| 里程碑 | 会来的功能（对用户可见） |
| --- | --- |
| M3 | 知识库问答（RAG：上传文档 → 基于内容问答）、会话记忆 |
| M4 | 真实大模型接入（可切换供应商）、流式"打字机"输出、更丰富的工具集 |
| M5 | 登录与多用户、任务历史持久化（跨重启）、云上部署地址 |
| M6 | 用量统计、成本明细、SLO 保障 |
